# Predicting ncRNA-Drug Associations via Sparse Virtual Edge Propagation and a Separated Residual Graph Transformer

Overview
The code for paper "Predicting ncRNA-Drug Associations via Sparse Virtual Edge Propagation and a Separated Residual Graph Transformer". The repository is organized as follows:

'data/disease (mRNA)' is the interaction data of mirna, lncrna and drug with diseases mRNA respectively
'data' contains all the association data, as well as the sequence and structural information of lncRNAs, miRNAs and drugs
'code/feature' is the RNA and drug feature extraction
'code' contains the code for the SVE-SRGT

Requirements
*Python 3.12.3 with PyTorch 2.5.1 and CUDA 12.8. *numpy == 2.0.1 *pandas == 2.2.3 *sklearn == 1.5.2
